# Blazma Get 1.1.1 🛠️

إصلاح مهم لإضافة المتصفح. **إذا عندك 1.1.0 ثبّت هذا الإصدار فوقه.**

## التحميل

| الملف | لمين؟ |
|---|---|
| **`BlazmaGet-Setup-1.1.1.exe`** | ويندوز 10 و11 (**مستحسن**، ما يحتاج Java) |
| `BlazmaGet-Portable-1.1.1.zip` | ويندوز بدون تثبيت |
| `blazma-get_1.1.1_amd64.deb` | لينكس (Ubuntu وDebian) |
| `BlazmaGet-1.1.1.jar` | أي نظام فيه Java 11+ |
| `BlazmaGet-Chrome-Extension.zip` | إضافة المتصفح (موجودة كمان داخل البرنامج: الإعدادات ← المتصفح) |

لو طلع لك "Windows protected your PC" اضغط **More info** ثم **Run anyway**.

🧩 طريقة تثبيت إضافة المتصفح بالصور: [docs/BROWSER-EXTENSION.md](https://github.com/mr-kateba/Blazma-Get/blob/HEAD/docs/BROWSER-EXTENSION.md)

## الإصلاحات

- 🧩 زر **افتح مجلد الإضافة** في الإعدادات ← المتصفح كان يطلع "تعذّر تجهيز مجلد الإضافة" في النسخة المثبّتة (ويندوز ولينكس). الحين يشتغل
- 🧩 خطوات تثبيت الإضافة داخل البرنامج صارت بنفس أسماء أزرار Chrome بالعربي ("وضع مطوّر البرامج" و"تحميل إضافة تم فك حزمتها")
- 📁 مسار الحفظ في نافذة التحميل الجديد صار يظهر بالترتيب الصحيح في الواجهة العربية

**English:** Fixes "Open extension folder" (Settings > Browser), which failed with "Unable to prepare the extension folder" in the installed app on Windows and Linux: the bundled Java runtime has no zip file system, so the extension is now copied out with plain `JarFile`. The in-app setup steps use Chrome's own Arabic labels, and the "Save in" path reads left to right in the Arabic UI. A step-by-step extension guide with screenshots is in [docs/BROWSER-EXTENSION.md](https://github.com/mr-kateba/Blazma-Get/blob/HEAD/docs/BROWSER-EXTENSION.md).
