# Blazma Get 1.0.0 🎉

أول إصدار من **Blazma Get**: مدير تحميل مجاني ومفتوح المصدر بواجهة عربية كاملة، بديل لـ IDM بدون كراك وبدون فيروسات.

## التحميل

| الملف | لمين؟ |
|---|---|
| **`BlazmaGet-Setup-1.0.0.exe`** | ويندوز 10 و11 (**مستحسن**، ما يحتاج Java) |
| `BlazmaGet-Portable-1.0.0.zip` | ويندوز بدون تثبيت |
| `blazma-get_1.0.0_amd64.deb` | لينكس (Ubuntu وDebian) |
| `BlazmaGet-1.0.0.jar` | أي نظام فيه Java 11+ |
| `BlazmaGet-Chrome-Extension.zip` | إضافة المتصفح (موجودة كمان داخل البرنامج: الإعدادات ← المتصفح) |

لو طلع لك "Windows protected your PC" اضغط **More info** ثم **Run anyway**.

## المميزات

- 🇸🇦 واجهة عربية كاملة من اليمين لليسار بخط عربي واضح، و20+ لغة ثانية
- ⚡ تحميل أسرع بتقسيم الملف لأجزاء
- 🔌 يكمّل لحاله لما يرجع النت، حتى لو سكّرت البرنامج وفتحته
- 🐢 تحديد السرعة بضغطة من الشريط العلوي
- 🌙 جدولة التحميل (مثلًا من 2 بالليل لين 7 الصبح)
- 📋 يراقب الروابط المنسوخة مثل IDM
- 🖱️ سحب وإفلات الروابط، واختصارات Ctrl+N وCtrl+V وDelete
- ✅ فحص سلامة الملف SHA-256
- 🔔 إشعار لما يخلص التحميل
- 🎬 تحميل الفيديو (HLS وDASH) والتقاط التحميلات من المتصفح

📄 التقرير الكامل: [docs/REPORT.md](https://github.com/mr-kateba/Blazma-Get/blob/HEAD/docs/REPORT.md)

**English:** First release of Blazma Get, a free and open-source download manager with a native Arabic (RTL) interface, based on [XDM](https://github.com/subhra74/xdm) (GPL-2.0). Highlights: automatic resume when the connection returns (even across restarts), one-click speed limit, scheduler, clipboard monitor, drag and drop, keyboard shortcuts, SHA-256 check, built-in browser extension setup, and a fix for file corruption when XDM resumed after a network error. Download `BlazmaGet-Setup-1.0.0.exe` for Windows.
