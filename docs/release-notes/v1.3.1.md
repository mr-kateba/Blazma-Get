# Blazma Get 1.3.1 ⚡

**تحميل الفيديو صار يبدأ على طول**، وتحميلات أكثر في نفس الوقت، وإصلاحات في إضافة المتصفح.

## التحميل

| الملف | لمين؟ |
|---|---|
| **`BlazmaGet-Setup-1.3.1.exe`** | ويندوز 10 و11 (**مستحسن**، ما يحتاج Java) |
| `BlazmaGet-Portable-1.3.1.zip` | ويندوز بدون تثبيت |
| `blazma-get_1.3.1_amd64.deb` | لينكس (Ubuntu وDebian) |
| `BlazmaGet-1.3.1.jar` | أي نظام فيه Java 11+ |
| `BlazmaGet-Chrome-Extension.zip` | إضافة المتصفح (موجودة كمان داخل البرنامج: الإعدادات ← المتصفح) |

**مهم:** بعد التحديث حدّث الإضافة كمان: من البرنامج اضغط **الإعدادات ← المتصفح ← Chrome ← افتح مجلد الإضافة**، وبعدين في صفحة الإضافات اضغط زر التحديث ↻ على Blazma Get.

## الإصلاحات

- ⚡ **الفيديو يبدأ يتحمّل على طول**: كان البرنامج يقرأ صفحة الفيديو من جديد مرتين (مرة للصورة ومرة للصوت) بعد ما اخترت الجودة، وهذا ياخذ وقت طويل في يوتيوب. الحين يستخدم نفس القراءة اللي سواها لما فتح نافذة الجودة
- 🚦 **ما عاد تعلق التحميلات على "بالانتظار"**: كان البرنامج يحمّل ملف واحد بس في نفس الوقت، والباقي ينتظر. الحين يحمّل 4 مع بعض (تقدر تغيّرها من الإعدادات ← التحميلات)
- 🧊 **ما عاد يعلق التحميل** لو تحديث أداة يوتيوب اليومي تأخّر أو النت وقف وهو يقرأ الصفحة
- 🧩 **إضافة المتصفح**:
  - المتصفح ينوّم الإضافة بعد شوي، وأول تحميل بعدها ممكن يفلت منها وينزل بالمتصفح. الحين تنتظر البرنامج يرد قبل لا تقرر
  - مفتاح **التقاط التحميلات** كان يرجع يشتغل لحاله، الحين يتذكّر اختيارك
  - أخف على المتصفح: شلنا الرسائل الكثيرة اللي كانت تنكتب مع كل طلب

**English:** Video downloads start right away: the download reuses the page lookup from the quality window instead of reading the page again for the video and again for the audio. Four downloads run at once by default (it was one, so others sat "waiting"); older installs on the old default are raised once. A slow daily yt-dlp update or a stalled page lookup can no longer freeze downloads. Extension: a download that wakes the sleeping extension waits for the app instead of slipping through to the browser, the Catch downloads switch is remembered, and per-request logging is gone.
