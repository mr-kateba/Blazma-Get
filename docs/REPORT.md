## 1. الملخص

**Blazma Get** مدير تحميل مجاني ومفتوح المصدر بواجهة عربية كاملة من اليمين لليسار، بديل لبرنامج IDM المدفوع. مبني على مشروع [Xtreme Download Manager (XDM)](https://github.com/subhra74/xdm)، وأضفنا عليه التعريب وهوية بلازما ومميزات جديدة، وأصلحنا مشاكل في المحرك الأصلي.

| | |
|---|---|
| التعديلات | 8 مجموعات تعديلات، 139 ملف، حوالي 4,100 سطر مضاف |
| الاختبارات الآلية | 264 اختبار، كلها ناجحة |
| ملفات النشر | ملف تثبيت ويندوز، نسخة بدون تثبيت، حزمة لينكس، ملف jar، إضافات المتصفح |
| البناء التلقائي | GitHub Actions يبني ويختبر مع كل تحديث، وينشر الإصدار تلقائيًا |

## 3. اللي تم إنجازه

### المرحلة 1: التجهيز
- نقل كود XDM مع تاريخه الكامل للمستودع (يسهّل جلب تحديثات المطوّر الأصلي لاحقًا)
- إضافة ملف الترخيص GPL-2.0

### المرحلة 2: التعريب
- ترجمة **كل** نصوص البرنامج للعربي (أكثر من 500 نص)، بلهجة بسيطة وواضحة
- اتجاه **من اليمين لليسار** لكل النوافذ والقوائم تلقائيًا
- خط عربي واضح: **IBM Plex Sans Arabic** (ترخيص مفتوح)
- الأرقام إنجليزية دائمًا (1 2 3) عشان ما تختلط الأنواع
- الأحجام والسرعات والمسارات تنعرض بالترتيب الصحيح وسط النص العربي
- يختار العربي تلقائيًا لما يكون جهازك عربي، وتقدر تغيّر لأكثر من 20 لغة

### المرحلة 3: الهوية
- شعار جديد: السداسي البرتقالي من هوية بلازما مع سهم تحميل
- ألوان بلازما (البرتقالي `#FF6D00`) في الوضع الداكن والفاتح
- الاسم **Blazma Get** في كل مكان: البرنامج، ملف التثبيت، إضافة المتصفح، صفحة "عن البرنامج" (مع ذكر XDM ومطوّره)

### المرحلة 4: المميزات
| الميزة | الحالة |
|---|---|
| جدولة التحميل (مرة وحدة أو أسبوعيًا، وقت بداية ونهاية) | ✅ موجودة في XDM، عرّبناها وأصلحنا عرض الوقت |
| تحديد السرعة | ✅ وأضفنا **زر سريع** في الشريط العلوي |
| **التكملة التلقائية لما يرجع النت** | ✅ جديدة بالكامل، وتشتغل حتى بعد إعادة تشغيل البرنامج |
| إشعار لما يخلص التحميل | ✅ نافذة أو إشعار ويندوز |
| **مراقبة الروابط المنسوخة** (مثل IDM) | ✅ جديدة |
| **السحب والإفلات** | ✅ جديدة |
| **اختصارات الكيبورد** (Ctrl+N، Ctrl+V، Delete) | ✅ جديدة |
| **فحص سلامة الملف SHA-256** | ✅ جديدة |
| **إضافة المتصفح داخل البرنامج** مع دليل تثبيت بالعربي | ✅ جديدة |
| قائمة للأيقونة جنب الساعة (فتح، تحميل جديد، خروج) | ✅ جديدة |

### المرحلة 5: النشر
- README احترافي بالعربي والإنجليزي، فيه صور من البرنامج
- ملف تثبيت لويندوز (Inno Setup) بواجهة عربية، ما يحتاج صلاحيات مسؤول ولا تثبيت Java
- GitHub Actions: يبني ويختبر مع كل تحديث، ولما ننشر وسم مثل `v1.0.0` يطلع الإصدار كامل بملفاته

## 7. التثبيت والبناء

**للمستخدم:** من [صفحة آخر إصدار](https://github.com/mr-kateba/Blazma-Get/releases/latest) نزّل `BlazmaGet-Setup-1.0.0.exe` وشغّله.

**للمطوّر:** يحتاج JDK 21 وMaven:

```bash
mvn clean package                      # البناء
java -jar xdm-app/target/xdm-app.jar   # التشغيل
mvn test -DskipTests=false             # الاختبارات
```
